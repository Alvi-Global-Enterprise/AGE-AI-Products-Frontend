# Duewise

Client-ready frontend for **Duewise** — automated invoicing and AI-driven debt/payment recovery.

## Stack

- React (Vite) + JSX
- Tailwind CSS v4
- Framer Motion
- Lucide React
- React Router

## Run

```bash
npm install
npm run dev
```

Open the app and start at `/auth`. Sign in with any valid email/password (8+ chars) or Continue with Google to enter the demo.

## Screens

| Route | Description |
|-------|-------------|
| `/auth` | Sign in / Sign up with role preview |
| `/dashboard` | KPI cards, cash forecast, AI predictions, channel tracker |
| `/invoices` | Filterable invoice table with AI actions |
| `/insights` | AI insights deep-dive |
| `/cashflow` | Extended cash flow view |
| `/integrations` | QuickBooks + partner connections |
| `/settings` | Workspace preferences |
